# result_example

result_example

## Usage

``` r
result_example
```

## Format

A list of dataframes corresponding to apply_NeighborFinder() results.

- res_CRC_JPN :

  edge table of Escherichia coli neighbors with only Japanese patients
  diagnosed with colorectal cancer

- res_CRC_CHN :

  edge table of Escherichia coli neighbors with only Chinese patients
  diagnosed with colorectal cancer

- res_CRC_EUR :

  edge table of Escherichia coli neighbors with only European patients
  diagnosed with colorectal cancer
